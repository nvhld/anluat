## Non-Negotiables

- Quick Exit is not React.
- Agent2UI never renders raw HTML, JS, iframe or unknown component.

- Payment UI is only built if MVP-B is enabled.

## Acceptance Focus

- Mobile first action visible.
- 320px no horizontal overflow.
- React islands lazy and bounded.
- Fallback UI exists.
